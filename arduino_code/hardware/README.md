# Hardware

This folder contains hardware documentation, circuit diagrams, wiring details, and sensor connection information for the Sleep Pattern Tracker project.

## Components Used

- Arduino UNO
- MAX30102 (Heart Rate & SpO₂ Sensor)
- MPU6050 (Accelerometer & Gyroscope)
- MAX4466 (Microphone Module)
- Breadboard
- Jumper Wires
- I2C Level Shifter

## Purpose

The hardware setup is designed to collect physiological and environmental data during sleep for analysis and sleep quality assessment.

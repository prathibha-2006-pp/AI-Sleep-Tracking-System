# AI-Sleep-Tracking-System
AI-Sleep-Tracking-System is a low-cost IoT-based healthcare project designed to monitor and analyze student sleep patterns using multiple sensors. The system collects heart rate, body movement, and sound data during sleep and generates insights about sleep quality and disturbances.
## Problem Statement
Many students experience poor sleep due to academic stress, irregular schedules, late-night mobile usage, and mental fatigue. Poor sleep affects concentration, memory, productivity, and overall well-being.

This project aims to provide an affordable sleep monitoring solution that helps students understand and improve their sleep quality.
## Hardware Components

- Arduino UNO
- MAX30102 (Heart Rate & SpO₂ Sensor)
- MPU6050 (Accelerometer and Gyroscope)
- MAX4466 (Microphone for Snore Detection)
- Breadboard
- Jumper Wires

  ## Features

- Heart Rate Monitoring
- Body Movement Detection
- Snore and Sound Monitoring
- Real-Time Sensor Data Collection
- Sleep Quality Assessment
- Low-Cost Hardware Design
